# Auditor Filosófico

Plugin de instrucciones para examinar evidencia, conceptos, argumentos y supuestos con selección del enfoque y autocrítica explícita. Utiliza el modelo y las herramientas disponibles en Claude.

## Uso

Selecciona la skill `auditar` en Claude o utiliza `/auditor-filosofico:auditar` en Claude Code. Aporta el texto que deseas analizar e indica tu objetivo.

Ejemplos:

1. «Auditor Filosófico: analiza este argumento y distingue qué afirmaciones están respaldadas por la evidencia que adjunto: [texto]».
2. «Auditor Filosófico: examina cómo se utiliza el concepto de libertad en este ensayo: [texto]».
3. «Auditor Filosófico: compara estas dos posturas, identifica sus premisas y formula las objeciones más fuertes: [textos]».

Puedes pedir un análisis rápido, estándar o profundo. La verificación externa depende de las herramientas y permisos disponibles. El análisis requiere criterio humano y no garantiza que sus conclusiones sean correctas.
