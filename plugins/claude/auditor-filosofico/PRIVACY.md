# Política de privacidad de Auditor Filosófico

Última actualización: 13 de noviembre de 2026.

## Alcance y funcionamiento

Esta política corresponde al plugin de Claude publicado en `plugins/claude/auditor-filosofico` de este repositorio. El plugin contiene instrucciones y referencias para que Claude examine textos, conceptos y argumentos a petición del usuario. No incorpora servidores MCP, servicios de almacenamiento, cuentas de usuario ni telemetría propia.

## Datos utilizados

Claude puede leer el contenido que el usuario le proporcione para la auditoría y el contexto de la conversación disponible para atender esa petición. Ese contenido puede incluir datos personales. El plugin no requiere aportar nombres, correos, direcciones ni otros datos identificativos para funcionar. Se recomienda omitir o anonimizar los datos personales que no sean necesarios.

El desarrollador no recibe ni almacena el contenido de las conversaciones por medio del plugin. El plugin no incorpora un servicio propio que conserve esos datos, ni envía el contenido a servicios del desarrollador o a otros destinos configurados por él.

## Claude y herramientas de la plataforma

El procesamiento, conservación y eliminación de las conversaciones por Claude dependen del producto, plan, configuración y condiciones de Anthropic. Esta política no modifica esas condiciones ni promete que Anthropic no conserve los datos.

- [Política de privacidad de Anthropic](https://www.anthropic.com/legal/privacy)

Si el usuario solicita verificación externa y Claude emplea herramientas disponibles en su entorno, las consultas y los datos necesarios para utilizarlas se rigen también por las condiciones y políticas de sus proveedores. El plugin no añade conectores propios.

## Conservación y control

Al no recibir las conversaciones mediante el plugin, el desarrollador no mantiene una copia que pueda consultar o eliminar. El usuario debe gestionar su historial y sus controles de datos en Claude y, cuando corresponda, en los servicios que haya elegido utilizar.

## Contacto y soporte

Las consultas sobre el plugin o esta política pueden dirigirse al [repositorio de soporte](https://github.com/novanoticia/auditor-filosofico/issues). Los mensajes publicados allí son públicos: no incluyas conversaciones privadas, credenciales ni otros datos sensibles.
