# Auditor Filosófico v0.2.0

**Contribuidor: Codex.**

Los ZIP importables de Mistral Le Chat y Perplexity están ahora incluidos en `downloads/` del repositorio y enlazados desde el README y las guías. Puedes descargarlos y subirlos directamente a Skills, sin ejecutar Python ni buscar los adjuntos de una release.

## Cambios

- `python3 scripts/build.py` regenera automáticamente ambos ZIP junto con las adaptaciones. `--check` y la validación detectan ZIP ausentes o desactualizados.
- Las skills incorporan la versión de `project.json` en sus metadatos YAML. Los ZIP tienen `SKILL.md` y `LICENSE` en la raíz.
- El empaquetado es determinista y no depende de la versión de zlib. Los adjuntos de la release usan los mismos bytes que las copias del repositorio.
- Al cambiar la versión en `project.json` en `main`, GitHub Actions regenera, guarda y valida los archivos y publica la release con sus notas y descargas. Las releases ya publicadas se conservan.

## Descargas

- Mistral: `auditor-filosofico-le-chat-skill.zip`.
- Perplexity: `auditor-filosofico-perplexity-skill.zip`.
- Markdown importables: `auditor-filosofico-le-chat-SKILL.md` y `auditor-filosofico-perplexity-SKILL.md`.
- Paquetes de distribución: `auditor-filosofico-chats-web.zip` y `auditor-filosofico-skill.zip`.
- `SHA256SUMS`: sumas de comprobación de las descargas.

El ZIP de distribución para chats web se extrae; los dos ZIP específicos de skill se suben directamente al importador. La validación local comprueba los archivos y su sincronización; la aceptación y el comportamiento en las cuentas de los proveedores siguen pendientes de evaluación.
