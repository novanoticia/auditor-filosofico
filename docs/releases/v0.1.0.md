# Auditor Filosófico v0.1.0

**Contribuidor: Codex.**

Primera release del auditor para examinar evidencia, conceptos, argumentos y supuestos con el modelo de la plataforma anfitriona. Incluye selección automática del enfoque, autocrítica, auditorías bajo petición, acompañamiento con activación expresa y perspectiva LessWrong opcional.

## Descargas

- **Mistral:** `auditor-filosofico-le-chat-skill.zip`. Súbelo directamente a Skills; incluye `SKILL.md` en la raíz, metadatos YAML y el método completo.
- **Perplexity:** `auditor-filosofico-perplexity-skill.zip`. Súbelo directamente a Skills; incluye el tratamiento de fuentes y citas.
- **Markdown independiente:** `auditor-filosofico-le-chat-SKILL.md` y `auditor-filosofico-perplexity-SKILL.md`, para importadores que aceptan un archivo Markdown.
- **Distribución para chats web:** `auditor-filosofico-chats-web.zip`, con prompts, instrucciones breves, guía y casos manuales. Se extrae; no se sube al importador de Skills.
- **Skill portable:** `auditor-filosofico-skill.zip`, con referencias y configuración de Codex, para clientes que admitan esa estructura.
- **SHA256SUMS:** sumas de comprobación de los archivos anteriores.

El código fuente incluye los plugins de Codex y Claude Code, sus marketplaces y las guías de instalación. Licencia MIT.

## Validación

Comprobadas la sincronización de adaptaciones, los manifiestos, enlaces, activación y empaquetado. Las pruebas de regresión verifican `SKILL.md` en la raíz, metadatos YAML, método íntegro, licencia y generación determinista de las skills web.

La aceptación en las cuentas de Mistral y Perplexity y la calidad de las auditorías están pendientes de evaluación. Las comprobaciones de archivos no certifican el comportamiento de los modelos.
